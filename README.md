# Bahagia Coffee And Street
## Digital Marketing Case Study

A real-world digital marketing project focused on social media content development and performance analysis for Bahagia Coffee And Street, a local coffee shop.

## 1. Project Overview

This project documents the process of developing digital marketing content for Bahagia Coffee And Street.

The main focus is to improve social media activity, develop engaging short-form video content, and evaluate content performance.

## 2. Project Background

The business's social media account had been inactive for an extended period before the content production began.

Two short-form videos have been produced as an initial effort to reactivate the account and rebuild its online presence.

## 3. Project Objectives

- Develop relevant social media content.
- Increase brand awareness through short-form videos.
- Improve audience engagement.
- Analyze content performance.
- Develop data-driven marketing recommendations.

## 5. Key Learning

This project provides practical experience in understanding social media management, content production, digital marketing strategy, and performance evaluation.

One important consideration is that an inactive social media account may present challenges when rebuilding audience engagement. This will be evaluated further through performance data.
